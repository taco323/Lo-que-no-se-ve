# Lo-que-no-se-ve

Es una obra visual que aborda la complejidad de la salud mental contemporánea mediante un díptico que representa dos estados emocionales opuestos pero interconectados. La primera imagen, “Ruido”, retrata la sobrecarga mental provocada por pensamientos intrusivos, exigencias sociales, ansiedad y caos interior. La segunda imagen, “Silencio”, muestra el vacío posterior: una escena aparentemente tranquila que representa la desconexión emocional, el agotamiento psicológico y la dificultad para expresar lo que no se ve. La obra invita a reflexionar sobre cómo estos estados conviven en muchas personas, a menudo sin ser percibidos desde el exterior.

Este proyecto integra el aprendizaje automático (machine learning) como herramienta creativa en el proceso de construcción visual. Se emplearon modelos entrenados para clasificar y reorganizar grandes volúmenes de imágenes según patrones emocionales y compositivos, lo que permitió seleccionar elementos visuales coherentes con los conceptos de ruido mental y silencio interior. El aprendizaje automático también fue usado para detectar y aplicar modificaciones sutiles en expresiones faciales, entornos y texturas, contribuyendo así a intensificar el lenguaje simbólico de cada imagen. Lejos de reemplazar la creatividad humana, el machine learning funciona aquí como un asistente que amplifica las capacidades expresivas del artista, permitiendo explorar estados emocionales complejos a través de medios digitales contemporáneos. La obra se posiciona así en un cruce entre arte, tecnología y salud mental, usando algoritmos como una nueva forma de percepción y traducción emocional.
